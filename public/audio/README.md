# Audio de la canción

Por derechos de autor no se incluye el archivo de audio de "Flores Amarillas" (Floricienta) en este repositorio.

Para activar el reproductor real:

1. Consigue el archivo de audio (por ejemplo `flores-amarillas.mp3`).
2. Colócalo en esta carpeta: `public/audio/flores-amarillas.mp3`.
3. Vuelve a desplegar el sitio.

Si el archivo no está presente, el sitio automáticamente muestra un reproductor **simulado** con un visualizador animado, sin romper la experiencia.
